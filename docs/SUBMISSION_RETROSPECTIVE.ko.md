# [회고] 제출 횟수 20회를 다 쓰고 나서 느낀 점

안녕하세요. 이번 대회를 마치고 가장 아쉬웠던 부분은 모델보다 **제출 횟수 관리**였습니다.

하루 제출 한도가 20회라는 것을 너무 늦게 알았고, 마지막에 `weight 0.50 → 0.51 → 0.52`로 점수가 계속 오르는 상황에서 다음 후보를 확인하지 못했습니다. 제출 버튼이 막힌 뒤에야 미리 횟수를 남겨뒀어야 했다는 생각이 들었습니다.

| 아쉬웠던 점 | 다음에는 이렇게 해보려고 합니다 |
|---|---|
| 비슷한 후보를 여러 개 제출 | 로컬에서 예측 차이를 먼저 비교하고 대표 후보만 제출 |
| 단일 validation 결과에 의존 | 유사 이미지까지 묶은 Group 3-fold OOF 사용 |
| 큰 모델·고해상도에 많은 시간 사용 | 오답 유형과 모델 간 disagreement부터 분석 |
| 마지막 제출 횟수를 남기지 못함 | 최소 5회는 최종 미세조정용으로 보존 |

제가 다음 대회에서 사용하려는 배분은 단순합니다.

- 5회: 모델·프롬프트의 큰 방향 확인
- 5회: 앙상블 weight 탐색
- 5회: OOF router와 선택적 답변 교체
- 5회: 최종 미세조정 및 비상용

이번에는 제출을 많이 하는 것보다 **어떤 후보를 제출하지 않을지 결정하는 검증 과정**이 더 중요하다는 것을 배웠습니다. 비슷하게 마감 직전에 제출 횟수가 부족했던 분들께 조금이나마 참고가 되면 좋겠습니다.

모두 정말 고생 많으셨습니다!
